Privacy

Updated 2026-11-24.

The app

Bulk Media Downloader runs on your computer. The links you paste and the files you download stay on your computer: the app downloads straight from the sites you link to, using your own internet connection. We do not run servers that receive your links or files.

The app connects to the internet only to download the links you give it, to check for a newer version of its download engine (from PyPI, the Python package index), and to check whether a newer version of the app is out (from GitHub). These requests carry no information about you or your downloads.

Settings and a small log file are kept in your user folder (%LOCALAPPDATA%\Bulk Media Downloader). Uninstalling the app removes the program; you can delete that folder too.

This website

This website uses no cookies, no analytics and no ads. It is hosted on GitHub Pages; GitHub may log technical data such as IP addresses to run and protect its service. The download is served by GitHub.
