# Bulk Media Downloader

Free Windows app: paste up to 100 links from Instagram, TikTok and YouTube and get every video and photo in one folder (and one ZIP if you like).
Website: https://bulkmediadownloader.com

- `app/` the app: a small local server (`bmd.py`), the downloads (`engine.py`, built on yt-dlp), the self-updating download engine (`updater.py`) and the window (`ui.html`)
- `packaging/` the Windows build (embedded Python, ffmpeg, deno) and the Inno Setup installer
- `site/` the website (generated by `tools/make_site.py`), published on GitHub Pages
- `.github/workflows/build.yml` builds, tests and releases the installer when `VERSION` changes; `pages.yml` publishes the website

Download only content you created or have permission to use. Not affiliated with Instagram, TikTok or YouTube.
